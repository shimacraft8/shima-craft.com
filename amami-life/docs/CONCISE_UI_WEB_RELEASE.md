# Web0.4.0：必要な情報を先に、説明は開いて読む

2026-10-21。ユーザーの「実況より現在」「全体の文字が多い」に対応。黒金・フォント・地図の出典/配色・計算値と既存導線を保持。

## 変更

- 台風の入口と地図は「現在」。同時に「21:00時点」のような公式発表の対象時刻を必ず表示し、リアルタイムの現在地と誤認させない。取得失敗や期限切れは「保存」「保存位置」に分ける。
- 見出しを1つにし、名称・気象庁/全国/発表時刻を1箇所へ。「発表あり」や重複した肩書きを削除。時刻ボタンは「＋117時間」から日付と時刻へ。選択中の対象時刻と気圧/最大風速/瞬間風速が主役。
- 70%予報円の解説、更新方針、発表/取得、選択予報円の半径、データの範囲と地図の詳細出典は「予報の見方・出典」に集約。「予報円は暴風域とは異なる」は常時表示。気象庁公式と地理院へのリンクも常時表示。
- 天気の観測時刻を短く表示。古い観測/予報・欠測を隠さず、詳しい出典/取得時刻は1つの開閉欄へ。地域予報と地点の実況、日輪が装飾である区別は保持。
- 太陽/月の座標と説明、潮グラフの補間/欠測の説明、交通の利用案内、設定の保存/通信/出典を開閉へ。意味が重複する案内文を減らす。操作・検索・保存・メモの自動保存・公式空港ページの表示は継続。地震/津波/警報の未連携と緊急時の案内は常時のまま。
- 管理者解析・GA計測追加・Nativeの公開は今回も対象外。

## 検証

新規4試験は、現在ラベルが閲覧時刻へ進まず発表位置の時刻を保持すること、保存との区別、JSTの跨日/年境界、未取得・不正入力を検証。開発全体144件/公開専用113件を実施。実データで時刻切り替え/値/地図の同期、半径を詳細で確認。

ブラウザで320/390/1440px、320px文字拡大、日付/太陽/月/座標開閉、予報の見方と拡大図/閉じる、空港表示/閉じる、設定画面を確認。ID重複なし、横はみ出しなし、コンソールエラーなし。

ui-ux-pro-maxを参照。progressive disclosureの検索には直接対応する推奨がなく、再検索の可読性/行高/コントラストを参考に、ネイティブdetailsで段階的に情報を開示する一般的なUI原則を適用。web-design-guidelines最新版を取得してレビュー：意味のある見出し・ボタン・状態/時刻・テキスト代替、native summary、48px操作、フォーカス復帰と非移動の更新を維持。重複IDと装飾疑似文字を修正。

取得失敗・古い保存情報・空の確認は既存provider試験で継続検証。実機iOS/Android/VoiceOver/TalkBack/OS文字拡大/実機通信遮断は未確認。天文参考計算の独立精度照合・大規模負荷も未完了。無料枠、地理院/OSMの条件とキャッシュ制約は既存資料を継続。有料API追加なし。
