## 準備

Node/npmとロックファイルからルートで `npm ci`。SDK57対応のExpo Goまたは開発ビルドを使用します。今回の構成の目安はiOS16.4以上、Android7以上。配布前に最新版のSDK要件と対象実機で再確認します。[Expo SDK57](https://docs.expo.dev/versions/v57.0.0/)

```bash
cd apps/mobile
EXPO_NO_TELEMETRY=1 npx expo start --localhost
```

このloopback構成はMac上の開発用です。手元のスマートフォンからMacのlocalhostへは到達しません。実機向けLAN待受、OSファイアウォールの変更、HTTPSテストAPIの用意は、環境と公開範囲を確認してから行います。ローカルにNodeサーバーを起動するだけで実機の天気連携を確認済みとはしません。

Expo Webでの共通API接続試験は次です。値は公開バンドルに入るので、`EXPO_PUBLIC_*` に秘密情報を置きません。現クライアントはloopback HTTPだけを許可し、公開用URLはまだ設定していません。[Expo環境変数](https://docs.expo.dev/guides/environment-variables/)

```bash
# 別ターミナルでルートの PORT=4837 npm start を起動
cd apps/mobile
EXPO_PUBLIC_API_BASE_URL=http://localhost:4837 EXPO_NO_TELEMETRY=1 npx expo start --localhost --web
```
