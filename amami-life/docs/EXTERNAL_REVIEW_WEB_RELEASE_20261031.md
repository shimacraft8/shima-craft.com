## 構成と安全な公開範囲

公開版の正本はGitHubの `amami-life/` です。元の変更済みチェックアウトは読み取り専用を維持しました。Cloudflareの入口Worker `shima-craft-amami-life` に公開ページ用の互換処理を追加しています。元Worker `shima-craft-com-production` のデプロイは変更せず、API・認証・POST・Cookieは従来へ渡します。旧Nextの全体を別ソースで置き換えていません。

互換処理はNextのシリアライズ済みスクリプトを壊さず、対象公開HTMLのリンクと管理された追加CSS/JSを扱います。Reactのイントロ終了を待って追加UIを取り付けます。制作ページの広告はサーバー側タグ/プリロード除去とCSPの許可先制限で実行を防ぎます。旧Nextのシリアライズデータには広告タグ情報が残るため、元ソース対応時には整理が必要です。計測タグの追加・重複設置は行っていません。
