# Web 0.3.6：光の方位・潮位選択・台風・フライト

2026-10-20。ユーザーの「これら全てを反映」および継続中のSHIMA CRAFT Web公開指示の対象。Native・管理者解析は今回の公開対象外。

## 変更

- 黒金・既存白赤ロゴを維持。右上の制作・相談ボタンと専用ダイアログを削除。制作・相談はフッターの `/studio#service`・`/studio#contact` を維持。
- PC右列を太陽/月の方位図へ。地理院淡色タイル（色調加工、出典明記）の上に、選択地点から真北基準の出入り方向を表示。実線=出る方角、破線=入る方角。時刻・度数も文字表示。地域・日付と連動し、月タブはURL `celestial=moon` で保存。タブは矢印/Home/End操作に対応。
- SunCalc **1.9.0**を継続使用。月は選択JST日に重なるUTC2日を走査し、選択日の範囲へ絞る。出入りのない日は「なし」。地形/標高/大気・実際の可視性を表さない参考計算。新しいSunCalc 2系の異なるAPIと混同しない。独立した天文台データとの精度照合は未実施。
- 潮グラフのクリック/タップで時刻と予測高さを小さな吹き出し表示。画面遷移なし。キーボードの時刻スライダー/矢印/Home/End、Escapeで閉じる。毎時の天文潮位予測と直線補間を区別。欠測/非連続の翌日を埋めない。24:00は連続する翌日0時がある場合だけ表示。古仁屋/笠利へO9を流用しない。
- 気象庁の `targetTc.json` をサーバーで取得し、トップに発表対象の台風/TDを表示。**取得成功・鮮度内で空リストの場合だけ**「台風の情報はありません。」。初回未取得・更新失敗・古い保存情報を区別。取消/対象外化は成功した新しいリストで置換する。全国の対象であり、奄美への影響や全TD網羅を示さない。気象警報/地震/津波は未接続のまま。
- 台風がある場合は気象庁の**実況天気図PNG**を表示し、拡大と公式進路図へ案内。画像の対象時刻は台風発表時刻と別。6時間以上古い画像は非表示。**取得している画像は進路予報図ではない**。気象庁の対話型進路図の固定PNG提供仕様は未確認。推測URLや第三者の転載画像は使用しない。
- 下部の長い「気象庁の地域予報」詳細欄を削除。上部の天気/降水確率の要約、発表時刻、古さの警告、公式へのリンクは残す。
- 奄美空港リンクを `https://www.amami-airport.co.jp/flight/today` へ変更。「移動」でボタンを押すと公式ページをiframe表示。公式ページ内の到着/出発切り替えを実確認。閉じる/再読み込み/別タブの代替あり。元ページの内容・デザインを改変せず、当サイト側で定期再読み込みしない。

## 取得方式・無料運用

台風リストは5分キャッシュ、失敗時1分のバックオフ、同一プロセス内の同時取得をまとめる。10分未更新または発表から6時間で古い表示（アプリ独自の鮮度基準）。画像のURL/名前を公式配信先と所定ファイル形式に限定し、容量・PNGシグネチャ・寸法を確認。任意URLの中継機能は設けない。表示内容が変わらない毎分の鮮度確認では、DOMと画像を再取得しない。

メモリキャッシュはCloudflareのisolateごと。世界全体で1回の取得を保証する集中キャッシュではない。Cron/KV/D1/有料APIを追加していない。大量利用時の厳密な共有集約・負荷試験は今後の課題。

Cloudflare公式条件（2026-10-20確認）: Workers Freeはアカウント全体で10万リクエスト/日、CPU10ms/要求。ほかのプロジェクトも共用する。100人×24時間×1分更新=144,000要求/日となり、共有上流キャッシュだけで利用者のAPI要求が消えるわけではない。枠を超えない運用や常時無料を保証しない。

航空の独自表・毎分自動更新は**未実装**。公開API/転載許諾/更新間隔/空港からの協力は未確認。robots.txtの許可を転載許諾と見なさない。公式ページのiframe表示を、許諾済みデータAPIや即時運航保証と表現しない。独自表へ進める際は、空港/航空会社の提供条件を確認した上で、表示中のみ更新、共有キャッシュ、日付付き状態、成功取得時刻、更新失敗、遅延/欠航をそのまま扱う。外部への問い合わせは送信していない。

iframeの外部ページではCookie/解析等の独自通信があり得る。表示ボタンの説明・プライバシー案内へ記載。地理院タイルはブラウザから直接取得。個人の現在位置・メモ・認証情報は渡さない。

公式根拠: [台風情報の範囲](https://www.jma.go.jp/jma/kishou/know/typhoon/7-1.html)、[気象庁利用条件](https://www.jma.go.jp/jma/kishou/info/coment.html)、[地理院タイル利用](https://maps.gsi.go.jp/help/use.html)、[Workers Free上限](https://developers.cloudflare.com/workers/platform/limits/)、[空港公式](https://www.amami-airport.co.jp/flight/today)。
