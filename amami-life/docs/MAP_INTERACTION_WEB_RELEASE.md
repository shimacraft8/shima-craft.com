# Web0.3.7：地点を選べる太陽・月の地図と台風進路

2026-10-21。ユーザーの継続指示によるSHIMA CRAFTトップの改修。公開結果は末尾。管理者解析・計測追加・Nativeは今回の公開対象外。

## 実装

- 黒金・システムサンセリフ・白赤ロゴ・繊細な質感を維持。台風を小さな実況天気図から、奄美の位置と公式の予報中心/予報円を同時に見られる地図へ変更。PCは地図と予報値を並列、スマホは台風名→地図→時刻ボタン→予報値。時刻選択と地図上の点を同期し、気圧・最大風速・最大瞬間風速・円半径を表示。実データのみ。未取得値は「—」。
- 元の気象庁ページへ移動する必要なく拡大ダイアログ・ズーム・全体表示。複数の台風/TDは選択ボタン。該当なしは鮮度内の空リスト取得成功時だけ表示。失敗・未取得・古いキャッシュを区別。
- 気象庁 targetTc.json の現対象IDを検証し、forecast.json / specifications.json の発表時刻・台風番号・予報時刻・座標を照合。半径は公式メートルを地図へ、文字のkmは公式の丸め値がある場合はそちらを使用。任意URL・対象外IDを取得しない。サイズ上限・タイムアウト・リダイレクト拒否。同時取得をまとめる5分メモリキャッシュ、失敗時1分のバックオフ。
- 予報円は中心が入る確率70%で、台風の大きさ・暴風域ではない。中心を結ぶ点線は確定した進路ではない。強風域/暴風域、奄美への最接近日時や危険度は独自推定しない。現在の発表であり、ページの日付選択による過去情報ではない。
- 太陽/月は地理院地図をクリック/タップ、マーカー移動、矢印で地図移動後「中央を計算地点にする」から計算地点を変更。ズーム、拡大ダイアログ、元の地域へ戻す操作。真北基準の出入り方向と時刻をSunCalc 1.9.0でブラウザ計算。月もJST選択日を維持。地域変更で選択地点をリセット。任意地点は奄美大島周辺の範囲内。
- 選択座標はメモリ内だけ。サーバー・URL・localStorageに記録しない。地理院へ表示範囲のタイル番号と通常のリクエスト情報は送信される。GPS・有料地図・ジオコーディングAPIは追加なし。Leaflet1.9.4は地図表示時だけ遅延読込。
