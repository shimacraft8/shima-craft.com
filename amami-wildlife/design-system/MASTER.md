# 奄美大島の生き物大全のデザイン

目的: 親子・旅行者・島民が気軽に自然を知る。絵から発見する入口と、検索して調べる入口を同じページに持つ。フィールド同定や安全判断を提供するサイトではない。

ui-ux-pro-maxの初回提案は玩具向けの紫色Claymorphismで目的に合わず不採用。絞り込んだEditorial/Organicの知見を参考にし、ユーザーの絵の方向性を優先した独自の紙の手帖として実装。

## イラスト制作

1. 当該分類群の実写を公的機関・信頼できる観察者の資料から探し、実際に見る。
2. 色分け・嘴や耳・脚数・目の周り・甲羅など、特徴をプロンプトへ記録。
3. 背景透過で1種1素材。雌雄・成長段階・階級は混同しない。
4. 原画PNGを残し、WebPに縮小・圧縮して配信。alphaを検証。
5. 参照URL・プロンプト・生成方法・確認日・監修状態を台帳へ保存。

ルリカケスは黒い目の周りと淡い嘴、青と赤茶の羽色を残す。アリは働きアリ。作画上の簡略化を同定図と混同しない。
