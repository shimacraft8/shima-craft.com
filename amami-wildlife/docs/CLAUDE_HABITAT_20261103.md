# Claude / claude-opus-5 / effort high

## 結論:新規リリースブロッカーあり(ウミガメ2体)

読んだ6ファイル(model.js / forest.js / paper-world.js / voxel-animals.js / species-habitat.json / characters.png)から確認できた具体的不具合のみ。生態・分類の専門レビューは未完了。

### 最優先
**1) perch:'sea' は y=-1.2 にしたが x/z が海になっていない**
- アオウミガメ:shore(14,-32)+az-30°/13m →(7.5,-43.3)。terrainHeight≒**+0.64(海面上)**、model.js 自身の `onLand(7.5,-43.3)` も true。実質「砂浜の地中に埋まったカメ」で陸上問題は未解消。
- アカウミガメ:(19.3,-48.2) の海底≒-0.65。y=-1.2 は海底の0.5m下で体の下半分が砂に埋没。
- 原因:「ラグーンの海底」が terrainHeight に無い。valleyFloor は z=-43 で約-0.14、さらに walls が+0.6 乗るため岸近くは水面上になる。
- 対策:(a) 礁池をへこませる項(例:(10,-50) 半径30・深さ3程度の負 bump)を足し、shore から15-20mで海底を-2.5以下に。(b) 純関数テストを追加:全 `perch==='sea'` で `!onLand(x,z)` かつ `terrainHeight(x,z) < PERCH_HEIGHT.sea-0.6`。(c) 沖(z<-90)へ逃がす案は距離60mで小さすぎ非推奨。

### 高
**2)** forest.js の広葉樹ループは z=-34..105・terrainHeight>0.25 のみが条件で、砂浜側(shore z=-32付近)に樹冠つきの樹が生えうる。ヒカゲヘゴは shore 除外済みだが樹と下草(z≧-28)は未除外。砂地判定の追加を。
**3)** フェリエベニボシカミキリ:立ち枯れは (x-0.35, z+0.35)、絵は (x,z) で幹面から0.1-0.3m浮く。ビルボード回転で角度により明確に離れる。幹面に接地させる。
**4)** オリイコキクガシラコウモリ:岩陰の中心=奥へ1.8mの位置。「開口部を飛ぶ」意図なら開口縁の手前へ。現状は奥壁を背にした静止個体に見える。

### 中
**5)** voxel アオウミガメ:甲羅が高い(厚0.5/全長1.18≒0.42)。実物は低く扁平で0.25-0.3程度。椎甲板5・肋甲板4対は正しい。
**6)** characters.png:ウミガメが床に接地し影つき。「陸のカメ」印象を試作ページ側で再生産。海種は影なし/水中表現へ。voxel の `castShadow=true` も本番流用時に海底へ影を落とす。
**7)** ウサギ:後足(0.31)が前足(0.28)とほぼ同長。後足を明確に長く。
**8)** habitat 表記と配置の不一致:ワタセジネズミ・アカマタ(里)が cape/estuary、サシバ(里)は estuary の枝。JSON 文言か配置を揃える。
**9)** アマミ/トクノシマトゲネズミが floor に1.6m間隔で隣接。島ラベルはあるが「島ごとに別種」の説明と見た目が矛盾。別視点への分離を推奨。

注:高さは model.js の terrainHeight による概算(voxel-model.js は未読、量子化で±0.2程度)。
