# 360°の森・川・滝・海

2026-11-02 / 0.4.0

## 今回の変更
展示室と一本道のスクロールを廃止。目の高さから360度見渡す、一続きのThree.jsの自然空間へ変更しました。海に開いた谷、渓流、滝、河口、砂浜、森の斜面を同じ地形として描きます。ヒカゲヘゴの放射状の羽葉と幹の葉痕、常緑広葉樹、根、下草、着生する葉を独自の手続き的造形で表現しています。実在の森林や地図の厳密な再現ではありません。

- ドラッグ/スワイプで360度の向きと上下を変更。矢印ボタンとキーボードも使用可能。
- 背景クリックで一段寄り、もう一度で戻る。＋/−は2段階の画角調整。動物クリックは解説。
- 7か所の地上の視点間を移動。分類ごとの展示室ではなく同じ自然空間内の視点。
- 編集済み40項目を地形内に配置。選択した種の位置と方向へ移れます。
- 「森を出る」で白い分類別図鑑へ。「森に入る」で再開。
- 40点の実写、出典、ライセンス、亜種・標本等の注記、詳細URLを維持。
- 発見数はこのページで解説を開いた種類の数。端末保存や解析送信はしません。
- 自動の水/葉の動きを停止可能。OSの動きを減らす設定も参照。
- 非JS、?mode=2d、3D読み込み失敗時は静的な全40項目へ到達できます。

## 実装と引き継ぎ

Claude Opus 5がレビューと地形・配置の純粋関数model.jsを作成した時点で、Claudeのセッション利用上限に達しました。その後の描画・植生・操作・UI・テスト・公開はCodexが引き継いでいます。Claude Codeの思考量はCLI既定値、明示的なhigh/max指定はしていません。Claudeがブラウザ動作確認を実施したとする主張はありません。

新規API、外部モデル、画像、依存、フォント、有料サービスは追加していません。既存Three.js/画像と独自のコードで構築。データJSON・採用イラスト・実写は変更していません。

## 性能とアクセシビリティ

共通形状とInstancedMesh、結合した樹木、遠景の簡略樹冠を使用。モバイルは植生を削減、DPRと描画負荷に応じて品質を下げます。目標上限30fpsで、実機で30fpsを保証するものではありません。非表示/画面外/解説中/一時停止では継続描画を止めます。初回シェーダー準備完了まで読み込み表示を維持します。

方向と拡大には44px以上のボタン。可視フォーカス、解説のTab循環/Escape/フォーカス復帰、縮小画面のオーバーフロー、文字色、reduced-motionを確認。ピンチによるブラウザ拡大を無効にしません。WebGLのコンテキスト喪失では復旧を待ち、戻らなければ図鑑へ切り替えます。

## 残る限界

- 動物は既存の透過イラストを用いた2.5Dの切り抜きで、動物そのものの3Dモデルではありません。
- 全動物の網羅は未完了。編集済み40項目、文献の抽出記録1,179件、依頼リスト248名を混同しません。
- 地形・植物・大きさ・時間帯・動物の同所性は創作で、実際の観察経路や野外同定の根拠にはなりません。
- iOS/Android実機、物理タッチ、低性能GPU、OS reduced-motionの切り替え、スクリーンリーダー、200%文字拡大、実際のWebGL context lossは未検証。
- 生物学的な写真の同定・形態の専門家監修は未実施。

試験の実測結果は forest360-validation.json / forest360-tests.log / forest360-browser.json を参照。
