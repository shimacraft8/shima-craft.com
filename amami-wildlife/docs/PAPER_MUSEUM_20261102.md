## 3. 技術的に参考にした点と設計

参考サイトの実コードはReact/R3F、Three.jsのWebGPURenderer、GSAP、Lenis、glTFとKTX2を使用していました。こちらは既存の静的構成を維持し、**Three.js 0.187.0とビルド用esbuild 0.28.2だけ**を追加しました。Reactへの全面移行や新しい外部サービスはありません。

応用したのは、視点と注視点を別々に管理するカメラ、フレーム更新による小さな環境アニメーション、描画領域とHTML操作の分離、描画準備後のローディング解除です。参考の大きなモデル群は読み込まず、入口は人の目線の高さから見渡す連続した3Dの森へ作り直しました。曲がった幹・枝・樹冠・シダ・つる・根・倒木・岩・小道をコードで生成し、地面/樹皮/葉の微細な表現は手続き的なCanvasTextureで作っています。森全体の背景画像や参考サイトのモデルは使用していません。分類別の5展示室は紙の展示台の構成を維持しています。

`roomsFromSpecies` が分類データから展示室を生成します。分類が増えても共通展示室を生成でき、今回の40件が重複なくいずれか1室に属することをテストしています。未編集の魚・甲殻類・クモの部屋を、架空データで埋めてはいません。

## 4. 実装した動作

- 全画面・目線高約1.68mの3D森林の入口。頭上の樹冠、手前の大きな葉、下草、霞む奥の木々、小道と木漏れ日で奥行きを表現。
- 葉の揺れ、控えめな光の筋と浮遊粒子、ポインターに合わせた小さな視点変化。停止設定では動かしません。
- 森の操作UIを縮小し、＋マーカーはhover/キーボードフォーカスで名前を表示。通常の白い一覧ページは維持。
- 紙のページを開くローディング表示。偽の進捗率は表示しません。
- 5室への連続したカメラ移動。途中の入力で、現在位置から次の移動に切り替えます。重複したtweenを積みません。
- 初回入室で紙のパーツが立ち上がる演出、入口のごく小さな視点移動。自由歩行ゲームや360°パノラマの操作は実装していません。
- 葉と草の揺れ、紙の蝶の飛行/羽ばたき、水の波紋、室ごとの照明変更。
- 3枚ずつの写真展示。全件選択できるセレクト、前後ボタン、写真へのRaycasterによる直接クリック、名前ボタン。
- 紙の図鑑風のHTML dialog。写真・撮影者・利用条件・注記・既存の解説・出典・詳細URLを表示。存在しない大きさや保全状況は補完しません。
- Escape、明示的なTab/Shift+Tab循環、閉じた後のフォーカス復帰。同じ展示ページを維持します。
- 展示室・展示ページ・選択種・2DモードをURLへ反映。ブラウザの戻る際のページ復元にも対応。
- シーン上のホイール、横スワイプ、左右キー、分類ボタン。3D領域外とルート両端では通常のスクロールを維持。
- 2D切り替えでWebGLのリソースを解放。初期URL `?mode=2d` はThree.jsを読み込みません。
- 初期化/遅延モジュール取得失敗時は通常図鑑へ切り替え。WebGLコンテキスト喪失も処理。JavaScriptなしでも静的な40詳細リンクを残します。

### 描画負荷への配慮

森林の葉はInstancedMesh、幹/枝は結合メッシュへまとめ、画面サイズに応じて植生量と葉の分割数を減らしています。静止した影は毎フレーム描き直さず、場面変更/素材の読み込み時に更新します。

3Dコードは遅延読み込み。写真は展示中の3枚ずつ読み込み、テクスチャの保持上限は12枚です。室の造形も初回訪問時に生成します。移動終了後は他室を非表示にし、画面外・非表示タブ・動作停止中は連続描画を止めます。詳細表示中は環境アニメーションを停止します。

スマホのDPR上限1.35・約30fps、PC上限1.75・約60fpsを目標に制限し、描画が継続して遅い場合はDPRを1へ下げます。端末でのFPSを保証するものではありません。測定コード・確認時の描画数は `museum-validation.json`。圧縮前の3Dチャンクは約620KB、gzip相当約160KB（正確な値は検証JSON）。初期UIは約12KBです。画像を含む総転送量は閲覧内容により変わります。

## 7. ローカル起動

この `amami-wildlife` フォルダで、Node 22.23.4以降とPython 3を使用します。

```sh
npm ci
npm run build
npm test
npm run preview
```

開くURL: `http://127.0.0.1:4926/wildlife/`

2Dのみ: `http://127.0.0.1:4926/wildlife/?mode=2d#catalog`

ビルド済みの表示だけならNode不要です。

```sh
python3 -m http.server 4926 --bind 127.0.0.1 --directory public
```

`file://` で直接開く方式はfetch/ES modulesの制約があるため使用しません。ポート4926が使用中なら既存サーバーを再利用するか、別ポートを指定してください。
