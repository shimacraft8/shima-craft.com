# 図版と一覧の改修 0.3.0 / 2026-11-02

## 変更

- イシカワガエル、アオウミガメ、クロウサギの初期3図版を描き直し。自然な目、閉じた口、暗い輪郭とガッシュの塗りで後続の図版へ合わせた。
- アカウミガメを一次資料（環境省の奄美群島環境文化アトラス、沖縄美ら海水族館）から編集。横向きのアオウミガメを構図参照にし、前ひれ2枚/後ひれ2枚の接続位置を点検。初回のひれが不自然な案、ユーザー希望と異なる真上案は不採用。
- 実写はCommonsのStrobilomyces撮影・CC BY-SA 3.0。フランスの水族館の飼育個体であることを明記。最初のCC0写真候補は識別の確信が足りず不採用。
- ヘビ5種の最初のとぐろ案はユーザー指摘により不採用。文章で形を指定するだけの方法から、一本の中心線を頭から尾へたどる構造下絵→彩色→下絵照合へ変更。
- 最終5図版は頭/尾各1、分岐なし、首が奥の弧より手前、尾の細まりを目視。解剖学的正しさの専門監修ではない。画像の形をNodeテストで証明したとも扱わない。
- 一覧は哺乳類/鳥類/爬虫類/両生類/昆虫ごと。分類見出し・件数・ジャンプ、検索時の空分類非表示。最初は各分類6項目まで、全表示で40項目。全表示と絞り込みをURLへ保存。
- 白背景を保持し、丸い背景装飾を細い植物/流れの線へ変更。明朝の大きな見出し、図版と名前の間隔、角丸カードの扱いを見直し。PC横展示/停止/スマホ縦表示を保持。
