# 調査範囲と残課題

対象: 奄美群島全体と周辺海域の動物。昆虫・その他の節足動物・海洋無脊椎動物・渡り鳥・迷鳥を含む。植物・菌類は今回の対象外。

## 現在のデータ

- 編集済み39項目: 代表的な哺乳類、鳥類、爬虫類、両生類、昆虫。種と亜種のrankを別フィールドで保持。39種と表現しない。
- 文献候補1,179記録: 徳之島魚類497見出し、沖永良部魚類626見出し、トンボ56項目。原文のローマ字和名・学名、出典ID、PDFページ番号を保持。重複、sp.を含む。受理学名・現在の分布・誤同定訂正は未照合。
- 両魚類文献には抽出できなかった改行・見出しなどが残る。元文献の収録種数と抽出件数は一致しない。抽出件数を資料全件や群島の全種数として宣伝しない。
- トンボ最後の55/56は見出しが番号より上に配置されていたためPDF5ページの名称から補った。56は資料上の分類群数で、亜種を含む。
- 写真参照と生成は別。写真は資料として確認したが、画像はAI生成の新規作画。制作時に参考にした写真はそのまま転載していない。詳細の実写には別途Commonsで再利用条件を確認した30点を採用し、撮影者・ライセンス・出典を表示。人による簡易確認と専門家監修は区別。

資料URLと対象範囲は`data/sources.json`。取得PDFのsha256は`research/download-log.json`。研究用の第三者PDF・写真・抽出全文はローカルのみ。再取得はこのURLとhashを照合し`pdftotext -layout`を使う。通常ビルドには元PDFが不要。

## 完全目録に向けた優先順

1. 群島と島別の基幹目録を突合。魚類は群島全域・奄美大島・喜界島・与論島の文献を追加。現行魚類名表は名称の照合用で、奄美の分布根拠に流用しない。
2. 鳥類は日本鳥類目録第8版、野鳥の会の補遺・追加記録・月別記録を照合。留鳥/夏鳥/冬鳥/旅鳥/迷鳥を島・観察年ごとに扱う。ホシバシペリカンの訂正をモモイロペリカンとの2種に重複計上しない。
3. カエル9分類群・イモリ・爬虫類、海棲哺乳類、外来種と過去に根絶した種を追加。資料の図上の分布は文字抽出だけで確定しない。
4. 昆虫全目録（東2002など）と追加報告、アリの島別報告を突合。旧集計3千種台を現在の総数として使用しない。
5. クモ、ダニ、甲殻類、軟体動物、刺胞動物、棘皮動物、環形動物、海綿等を専門分野別に調査。海域・漂着・生体記録を区別。
6. 名称の異名統合、種と亜種の重複排除、記録の有効性を確認してから全種イラスト制作へ展開。

## ツヤミカドオオアリ

公的資料でCamponotus amamianusと奄美大島の分布を確認。日本最大という表現は、女王/働きアリ等の比較条件と一次資料によるサイズの裏付けを確定するまで不使用。画像はAntRoomの実写を確認して働きアリとして生成。全階級を示す図ではない。
