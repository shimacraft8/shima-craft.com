# 0.6.0 体験型の自然絵本 / 2026-11-03

## 変更

ユーザーが①自然絵本を選択し、その後「普通にスクロールするサイトではない」「Claudeも使用してレビューと改善を繰り返して」と補足。最初の縦読み案は公開せず、表紙を開いて森・渓流・海・巻末をめくる一冊へ改修した。

- 水平のネイティブscroll-snapをベースに、紙の回転・陰影・小口、背景/文字/動物の速度差、有限時間で静止するポインター奥行きを実装。
- 表紙を開く、前後、章ナビ、左右/Home/Endキー、マウスドラッグ、ネイティブの横スワイプ。縦スクロールを奪わず図鑑へ抜けられる。
- 森はヒカゲヘゴを参考にした照葉樹林、渓流は滝と苔むす岩、海は浅いサンゴ礁。描かれた景色は創作であり、実在地点や生息分布・縮尺・季節・昼夜の再現ではない。
- 主役3種と関連する生き物を景色へ配置。リュウキュウアオヘビは地面、ウミガメは水中。小動物が主役の体に重ならない配置に修正。
- 全40項目をイラスト/実際の写真/生態と出典の3ページの本で開ける。URL共有、戻る/進む、閉じる/Escape、タブ/前後/左右キー、横スワイプに対応。
- 分類別の一覧、名前・学名/島/すみか/渡り鳥の検索、静的詳細ページ、既存サイトへのリンク、canonical/サイトマップを保持。
- JavaScriptやデータ取得の失敗時も本物の詳細URLが残る。画像エラーは写真/詳細ページへ案内し、サンプルや別種の画像を代用しない。
- 白い図鑑、角ゴシック、大きな日本語、少ないコピー。トップの旧WebGLバンドルは公開資産から除外。旧3Dソースは履歴として保管。

## レビューと改善

ui-ux-pro-maxのEditorial/Organic知見を参考にし、一般的なピンク/SaaS配色は不採用。ブランドと対象の自然に合わせて判断した。新しい風景画3点はbuilt-in image_genで生成し、PNG原画・768/1536px WebP・全プロンプト・生成台帳を保存した。生成したのは風景画であり、実写として表示しない。

Claudeはclaude-opus-5 / effort highを使用。初期ソースのレビュー、修正再チェック、新体験の4ファイル実装、新体験の画面/ソースのレビューを実施。実装依頼は20ツールターン上限で終了し、Codexが差分を精査して作業を継続。機能と絵の仕上がりの両方を見直した。詳細はstorybook-claude-review.mdとstorybook-stage-claude-review.md。

主な修正: 実写のグリッド内での拡大、端のページへ進んだ後のフォーカス、OS設定変更時の停止ボタン、古い履歴stateの破棄、動作停止時の小画面ずれ、小画面の札の重なり、strict CSPで禁止されるインラインstyle、ページ面の縦ずれ、複数章ジャンプ中のsnap、画面外ページのinert化、静止状態でも本と分かる小口、過剰な白リングの削除。

最新のWeb Interface Guidelinesを2026-11-03に取得し、セマンティックな操作要素、フォーカス、モーション停止、画像寸法、URL状態、レスポンシブ、エラーとフォールバックを確認した。
