# 0.5.0 ブロックの森と40種の立体モデル

## 今回の変更

トップを独自のブロック地形・照葉樹・ヒカゲヘゴ・渓流・段差の滝・海辺へ更新。目線の高さで自由に歩ける一人称方式です。承認されたクロウサギ/アオウミガメの試作を基準に、掲載中の40種を実際の3Dブロックモデルへ統一しました。画像を板に貼ったモデルではありません。既存ゲームの素材やロゴは使用していません。

図鑑の白い一覧、透過イラスト40種、実写写真40種、解説・出典、既存SHIMA CRAFTへのリンクは保持しています。主なモデル定義はsrc/museum/voxel-animals.js、地形はvoxel-model.js、森はforest.js、配置とクリック判定はpaper-world.js/renderer.jsです。

- PC: 画面を選んでWASDで歩く、Shiftで早歩き、ドラッグ/矢印で見回す、Homeで入口へ。
- スマホ: 左のボタンを長押しで歩き、右のボタンの長押しかドラッグで見回す。＋−で画角を変更。
- 生き物や名前を選ぶと写真・解説が開きます。検索から40種それぞれの場所へ移れます。
- 森を出ると通常の図鑑。旧共有リンク、2Dでの解説リンクも維持。
- 木・岩との衝突、急な崖・深い水・端の柵を越えない移動。全7地点は木道/橋で接続し、道の外も歩けます。
- フォーカス喪失・ダイアログ・非表示で移動を解除。頭揺れや強制ポインターロック、ホイール奪取はありません。
- 動きを止めても手動で歩けます。OSの動きを減らす/データ節約は初期2D、明示的に森へ入れます。pinch-zoomを保持。

## 造形と生息場所

昆虫の脚は胸部から3対6本。ウミガメは前2/後2のひれを独立造形。ヘビは頭から先細りの尾まで一本の中心線でつなぎ、分岐・二重尾・不自然な巻き込みを避けました。鳥は2脚2翼1尾、カエル/ヤモリ/イモリは4肢です。種類ごとの色、模様、くちばし、顎、甲羅、耳、尾の長さを写真から簡略化。正面・側面・上面の検証画像はscreenshots/voxel-20261103/block-40-*.png。部位の記録はvoxel-anatomy.jsonです。

リュウキュウアオヘビは林床。海亀2種はラグーンの海面下かつ海底より上を泳ぐ配置へ。コウモリは洞窟開口部、カミキリ/クワガタは実際の幹面に脚を接地。砂浜の広葉樹/下草を除外。徳之島/請島限定の項目はラベルにも島名を追加し、トクノシマトゲネズミは別の観察点へ分離しました。

## 実機確認手順

1. Safari/Chromeで公開URLを開き、左右の長押しと同時ドラッグ。指を1本ずつ離しても操作が残らないことを確認。
2. 森→滝→河口→海へ歩き、木や岩に入り込まず深い水/崖へ落ちないことを確認。
3. 縦横回転、ホーム/復帰、画面ロック/復帰で操作が継続しないことを確認。
4. 全40種の検索、写真、出典、詳細ページ、森/図鑑への復帰を試す。
5. OSの動きを減らす、文字拡大、画面読み上げ、低電力/低速通信を試す。熱や電池消費が強ければ2Dへ。
