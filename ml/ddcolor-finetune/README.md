# DDColor 古写真ファインチューニングキット

ブラウザ内カラー化の高品質モデル（DDColor-T）を「経年劣化した日本の白黒写真」向けに
追加学習させるためのキット。**完全無料**（Google Colab の無料 GPU 枠を使用、カード不要）。

## 背景

ベースの DDColor は現代のきれいなカラー写真で学習されているため、
粒状ノイズ・退色・傷のある古い写真は学習分布の外となり、
出力が「全面うすいセピア」に崩壊しやすい。

このキットは現代のカラー写真を人工的に劣化させて
「古い白黒写真 → 正しい色」の学習ペアを合成し、モデルを再学習することで
劣化写真への耐性（ドメイン適応）を獲得させる。

## 使い方

1. [Google Colab](https://colab.research.google.com) を開く
2. 「ファイル」→「ノートブックをアップロード」→ `finetune_ddcolor_ja.ipynb` を選択
3. 「ランタイム」→「ランタイムのタイプを変更」→ **T4 GPU**
4. 上から順にセルを実行（手順・所要時間はノートブック冒頭に記載）
5. 最後に Google Drive へ `ddcolor_finetuned.zip` が出力される
6. 中身を `public/models/` へ上書きし、ノートブック末尾の反映手順に従う

学習が中断されても、再実行すれば Drive のチェックポイントから自動再開する。

## 事前検証済みの内容（2026-07-10）

以下はローカルで動作確認済みのため、Colab 上でも同じ挙動になる想定:

- HF `piddnad/ddcolor_paper_tiny` の config.json から DDColor-T を構築し
  `pytorch_model.bin` を読み込み（missing/unexpected キーなし）
- ONNX export（opset 17、入出力名 `input`/`output`、現行グラフと同一 I/O）
- onnxruntime との出力照合（最大誤差 0.044）
- 劣化シミュレーション（粒状・退色・傷・周辺減光・JPEG 劣化）と
  OpenCV float 経路での CIE Lab 変換（L: 0-100 / ab: 実スケール）

## 期待値の設定（正直な見込み）

- 改善するもの: 劣化した写真での「全面セピア崩壊」の頻度・程度
- 改善しないもの: モデル容量そのものの限界（DDColor-T のまま）
- quick 設定（5,000枚 / 6,000 steps ≒ 1〜2時間）でまず傾向を確認し、
  効果があれば full 設定（人物 25,000枚 / 20,000 steps）で本格学習を推奨
- 効果が乏しい場合のフォールバックは、色情報のみ外部 GPU で生成する
  ハイブリッド方式（Replicate 約1円/枚 または HF Space 無料枠）
